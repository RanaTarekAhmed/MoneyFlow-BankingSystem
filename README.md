💰 MoneyFlow – Online Banking Management System

🏦 MoneyFlow is a secure and modern Online Banking Management System built with ASP.NET MVC, Entity Framework Core, and SQL Server. It provides a complete banking solution for both customers and bank employees, allowing secure account management, money transfers, transaction tracking, and banking operations through an intuitive web interface.

✨ Features

* 🔐 Secure Authentication & Authorization
    * Customer & Employee login
    * Role-based access control
    * Secure password management
* 👤 Customer Account Management
    * View account details
    * Check account balance
    * Update personal information
* 💸 Money Transfers
    * Transfer funds between accounts
    * Balance validation
    * Automatic transaction recording
* 💵 Deposit & Withdrawal Management
    * Employee-controlled deposits
    * Employee-controlled withdrawals
    * Automatic balance updates
* 📜 Transaction History
    * View complete transaction records
    * Search and filter by date, account, or transaction type
* 👥 Customer Management
    * Create and manage customer accounts
    * Search and update customer information
* 📊 Dashboard & Reports
    * Banking activity overview
    * Recent transactions
    * Account statistics
* 📧 Email Notifications
    * Account creation
    * Deposits & withdrawals
    * Money transfers
    * Password changes
    * Security alerts
* 🛡️ Security
    * Authentication & authorization
    * Input validation
    * Transaction logging
    * Secure banking operations

🎯 Goal

MoneyFlow aims to simplify banking by providing customers with secure online banking services while giving bank employees powerful tools to efficiently manage accounts, transactions, and customer information—all within a centralized, reliable, and user-friendly platform.
